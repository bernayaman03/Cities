# Cities

A simple Android application developed with Kotlin and XML layouts. The app displays information about three cities in Türkiye: Istanbul, Ankara, and Izmir.

## Features

- Browse between three cities using previous and next buttons.
- Display a photograph for each city.
- Show the city name, license plate code, and a short description.
- Automatically hide navigation buttons at the beginning and end of the list.

## Technologies

- Kotlin
- Android SDK
- XML Layouts
- Android Studio

## Implementation

The application uses `LinearLayout`, `FrameLayout`, and `RelativeLayout` to organize its interface.

City information is stored in lists, and the `updateUI()` function updates the displayed content based on the selected index.

## Image Credits

City photographs are sourced from Wikimedia Commons and selected for their CC0 (Public Domain Dedication) licensing.

## Project Purpose

This project was developed as an Android programming exercise to practice XML layouts, UI components, event handling, and basic navigation logic.
